POLITIKERUNDERSØKELSE – OA

Filer:
index.html              selve siden
style.css               design
app.js                  funksjonalitet og innsending
oa-logo.png             logo
google-apps-script.gs   kode til Google Apps Script
labrador-embed.html     iframe-kode for Labrador

Før ekte innsending:
1. Lag et Google Sheet.
2. Åpne Extensions/Utvidelser > Apps Script.
3. Lim inn google-apps-script.gs og sett EMAIL_TO.
4. Deploy som Web app med tilgang for alle som har lenken.
5. Kopier webapp-URL-en inn i GOOGLE_SCRIPT_URL øverst i app.js.
6. Publiser mappen i et GitHub-repo med GitHub Pages.
7. Test først direkte, deretter med Labrador-iframe.

Siden står i testmodus helt til GOOGLE_SCRIPT_URL er fylt inn.
